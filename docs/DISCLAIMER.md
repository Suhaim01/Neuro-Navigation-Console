# Research software — not a medical device

This software is a research / engineering prototype of an intra-operative
neuronavigation console.

It is **not** a medical device.
It is **not** cleared, certified, or validated for clinical use.
It must **not** be used to diagnose, treat, monitor, or guide care of any patient.

Tracking and plan input in the prototype are simulated (`navsim`); registration uses
canned fiducial pairs. See the README end-goal section for intended procedure class
and caveats.
